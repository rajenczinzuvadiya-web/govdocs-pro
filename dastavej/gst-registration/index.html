GST નોંધણી

ધંધાનું વેચાણ નક્કી મર્યાદાથી વધુ હોય ત્યારે ફરજિયાત નોંધણી — gst.gov.in પર મફત.

ધંધો / દુકાન

શેમાં કામ આવે

કાયદેસર બિલ, ઇનપુટ ટેક્સ ક્રેડિટ, મોટી કંપની / સરકારને માલ વેચી શકાય.

કોણ કઢાવી શકે

  • વર્ષનું વેચાણ માલમાં ₹40 લાખ / સેવામાં ₹20 લાખથી વધુ હોય, બીજા રાજ્યમાં માલ વેચતા હોય કે ઓનલાઈન વેચાણ કરતા હોય

જરૂરી પુરાવા (4)

  1. માલિકનું PAN અને આધાર
  2. ફોટો
  3. ધંધાની જગ્યાનો પુરાવો (લાઈટ બિલ / ભાડા કરાર + માલિકની સંમતિ)
  4. બેંક ખાતાની વિગત

બીજા દસ્તાવેજ

  • Udyam (MSME) નોંધણીનાના-મોટા ધંધા / ઉદ્યોગની સરકારી નોંધણી — મફત, ઓનલાઈન અને આધારથી થાય છે.
  • ગુમાસ્તા ધારા નોંધણી (દુકાન / ઓફિસ)દુકાન, ઓફિસ કે ધંધાની જગ્યાની રાજ્યના કાયદા મુજબ નોંધણી / જાણ.
  • FSSAI નોંધણી (ખાવાની વસ્તુનો ધંધો)ખાવાની વસ્તુ બનાવવા, વેચવા કે હોટલ-લારી ચલાવવા માટે ફૂડ સેફ્ટીની નોંધણી / લાયસન્સ.

માહિતી: 27/11/26 સુધીની, સરકારી સાઇટ પરથી આપણા સરળ શબ્દોમાં. જાણકાર સરકારી એપ નથી, ફક્ત માહિતી આપે છે (અરજી કે સેવા નહીં); નિયમ, ફી કે તારીખ બદલાઈ શકે — અરજી પહેલાં સત્તાવાર સાઇટ પર ખાતરી કરો. ભૂલ દેખાય તો જણાવો.

યોજનાદસ્તાવેજજીવનના પ્રસંગઅમારા વિશેગોપનીયતા નીતિનિયમો અને શરતોડિસ્ક્લેમરકોપીરાઇટ નીતિ (DMCA)સંપર્ક
