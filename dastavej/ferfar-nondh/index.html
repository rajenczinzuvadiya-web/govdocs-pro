ફેરફાર નોંધ (ગામ નમૂના નં. 6 / હક્કપત્રક)

જમીનમાં વેચાણ, વારસાઈ, બોજો કે નામ ફેરની નોંધ — અને તેની નકલ.

જમીન / ઘરખેડૂત

શેમાં કામ આવે

નવો માલિક / વારસદાર ૭/૧૨ માં ચડે; લોન, સહાય અને વેચાણમાં જરૂરી.

કોણ કઢાવી શકે

  • જમીન ખરીદનાર, વારસદાર, લોન લેનાર ખેડૂત — જેની જમીનમાં નવો ફેરફાર થયો હોય.

જરૂરી પુરાવા (4)

  1. ફેરફારનો આધાર: નોંધાયેલો દસ્તાવેજ / પેઢીનામું + મરણનો દાખલો / બેંકનો બોજા પત્ર
  2. ૭/૧૨ અને ૮-અ ની નકલ
  3. આધાર કાર્ડ (બધા ખાતેદાર)
  4. ખેડૂત ખાતેદાર હોવાનો પુરાવો (ખરીદનાર માટે)

ટૂંકી વિગત

ફી
નકલ: મહેસૂલ વિભાગના દર પ્રમાણે

સત્તાવાર લિંક

  • AnyROR
  • iORA (મહેસૂલ વિભાગ)

અરજી હંમેશાં સત્તાવાર સાઇટ પર, ગ્રામ પંચાયત કે VCE પાસે જ કરો.

જાણકાર એપમાં ખોલો: સેવ કરો, પુરાવાનું ✓ લિસ્ટ વોટ્સએપ પર મોકલો

બીજા દસ્તાવેજ

  • ૭/૧૨ અને ૮-અ ની નકલખેતીની જમીનનો રેકર્ડ: ૭/૧૨ માં સર્વે નંબર, માલિક અને પાક; ૮-અ માં ખાતેદારની બધી જમીનની યાદી.
  • વારસાઈ નોંધ (જમીન વારસદારોના નામે)ખાતેદારના અવસાન પછી ૭/૧૨ માં વારસદારોનાં નામ ચઢાવવાં — i-ORA પર ઓનલાઈન અરજી.
  • ખેડૂત ખાતેદાર પ્રમાણપત્રતમે ગુજરાતના ખેડૂત ખાતેદાર છો તે બતાવતું પ્રમાણપત્ર.
  • ફાર્મર ID (ખેડૂત નોંધણી — Farmer Registry)દરેક ખેડૂતનો ડિજિટલ ઓળખ નંબર — આધાર અને જમીનના રેકર્ડ સાથે જોડાયેલો.
  • ઘરવેરા આકારણીમાં નામ (ઘરનો ઉતારો)ગામમાં ઘર / પ્લોટ પંચાયતના આકારણી રજિસ્ટરમાં પોતાના નામે કરાવવું અને ઉતારો મેળવવો.
  • વીજળી જોડાણ પોતાના નામે (નામ ફેર)ઘર ખરીદ્યા કે વારસામાં મળ્યા પછી લાઈટ બિલ પોતાના નામે કરાવવું.

માહિતી: 27/11/26 સુધીની, સરકારી સાઇટ પરથી આપણા સરળ શબ્દોમાં. જાણકાર સરકારી એપ નથી, ફક્ત માહિતી આપે છે (અરજી કે સેવા નહીં); નિયમ, ફી કે તારીખ બદલાઈ શકે — અરજી પહેલાં સત્તાવાર સાઇટ પર ખાતરી કરો. ભૂલ દેખાય તો જણાવો.
