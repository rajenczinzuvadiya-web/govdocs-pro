બિનખેતી (NA) પરવાનગી

ખેતીની જમીન પર ઘર, દુકાન કે ઉદ્યોગ બાંધવા જમીનને બિનખેતી કરવાની પરવાનગી.

જમીન / ઘરખેડૂતનાના વેપારી / દુકાનદાર

શેમાં કામ આવે

બાંધકામ પરવાનગી, બેંક લોન અને પ્લોટ વેચાણ કાયદેસર થાય.

કોણ કઢાવી શકે

  • ખેતીની જમીનનો ઉપયોગ રહેઠાણ, વાણિજ્ય કે ઉદ્યોગ માટે કરવા માગતા ખાતેદાર.

જરૂરી પુરાવા (5)

  1. ૭/૧૨, ૮-અ અને જૂની ફેરફાર નોંધો
  2. જમીનનો નકશો / માપણી શીટ
  3. પ્લાન અને લે-આઉટ
  4. આધાર કાર્ડ (બધા ખાતેદાર)
  5. જરૂર પડે તો બીજી કચેરીનાં ના-વાંધા પ્રમાણપત્ર

ટૂંકી વિગત

ફી
જમીન અને ઉપયોગ પ્રમાણે પ્રીમિયમ / રૂપાંતર કર

સત્તાવાર લિંક

  • iORA (મહેસૂલ વિભાગ)

અરજી હંમેશાં સત્તાવાર સાઇટ પર, ગ્રામ પંચાયત કે VCE પાસે જ કરો.

આ પ્રસંગમાં કામ આવે

  • 🏠 નવું ઘર / સરનામું બદલ્યું
જાણકાર એપમાં ખોલો: સેવ કરો, પુરાવાનું ✓ લિસ્ટ વોટ્સએપ પર મોકલો

બીજા દસ્તાવેજ

  • ૭/૧૨ અને ૮-અ ની નકલખેતીની જમીનનો રેકર્ડ: ૭/૧૨ માં સર્વે નંબર, માલિક અને પાક; ૮-અ માં ખાતેદારની બધી જમીનની યાદી.
  • વારસાઈ નોંધ (જમીન વારસદારોના નામે)ખાતેદારના અવસાન પછી ૭/૧૨ માં વારસદારોનાં નામ ચઢાવવાં — i-ORA પર ઓનલાઈન અરજી.
  • ખેડૂત ખાતેદાર પ્રમાણપત્રતમે ગુજરાતના ખેડૂત ખાતેદાર છો તે બતાવતું પ્રમાણપત્ર.
  • ફાર્મર ID (ખેડૂત નોંધણી — Farmer Registry)દરેક ખેડૂતનો ડિજિટલ ઓળખ નંબર — આધાર અને જમીનના રેકર્ડ સાથે જોડાયેલો.
  • ઘરવેરા આકારણીમાં નામ (ઘરનો ઉતારો)ગામમાં ઘર / પ્લોટ પંચાયતના આકારણી રજિસ્ટરમાં પોતાના નામે કરાવવું અને ઉતારો મેળવવો.
  • વીજળી જોડાણ પોતાના નામે (નામ ફેર)ઘર ખરીદ્યા કે વારસામાં મળ્યા પછી લાઈટ બિલ પોતાના નામે કરાવવું.

માહિતી: 24/11/26 સુધીની, સરકારી સાઇટ પરથી આપણા સરળ શબ્દોમાં. જાણકાર સરકારી એપ નથી; નિયમ, ફી કે તારીખ બદલાઈ શકે — અરજી પહેલાં સત્તાવાર સાઇટ પર ખાતરી કરો. ભૂલ દેખાય તો જણાવો.
