ઘરવેરા આકારણીમાં નામ (ઘરનો ઉતારો)

ગામમાં ઘર / પ્લોટ પંચાયતના આકારણી રજિસ્ટરમાં પોતાના નામે કરાવવું અને ઉતારો મેળવવો.

જમીન / ઘર

શેમાં કામ આવે

ઘરની માલિકીનો પુરાવો, વીજ / પાણી જોડાણ, આવાસ યોજના, બેંક લોન, સરનામાનો પુરાવો.

કોણ કઢાવી શકે

  • ગામમાં ઘર / પ્લોટ ખરીદનાર, વારસામાં મેળવનાર કે નવું ઘર બાંધનાર.

જરૂરી પુરાવા (4)

  1. ખરીદીનો દસ્તાવેજ / વારસાઈ (પેઢીનામું + મરણનો દાખલો)
  2. છેલ્લી વેરા પહોંચ
  3. આધાર કાર્ડ
  4. જૂના માલિકની સંમતિ (લાગુ હોય તો)

ટૂંકી વિગત

ફી
પંચાયતના નિયમ પ્રમાણે

સત્તાવાર લિંક

  • પંચાયત વિભાગ, ગુજરાત

અરજી હંમેશાં સત્તાવાર સાઇટ પર, ગ્રામ પંચાયત કે VCE પાસે જ કરો.

આ પ્રસંગમાં કામ આવે

  • 🕊️ કુટુંબમાં અવસાન
  • 🏠 નવું ઘર / સરનામું બદલ્યું
જાણકાર એપમાં ખોલો: સેવ કરો, પુરાવાનું ✓ લિસ્ટ વોટ્સએપ પર મોકલો

બીજા દસ્તાવેજ

  • ૭/૧૨ અને ૮-અ ની નકલખેતીની જમીનનો રેકર્ડ: ૭/૧૨ માં સર્વે નંબર, માલિક અને પાક; ૮-અ માં ખાતેદારની બધી જમીનની યાદી.
  • વારસાઈ નોંધ (જમીન વારસદારોના નામે)ખાતેદારના અવસાન પછી ૭/૧૨ માં વારસદારોનાં નામ ચઢાવવાં — i-ORA પર ઓનલાઈન અરજી.
  • ખેડૂત ખાતેદાર પ્રમાણપત્રતમે ગુજરાતના ખેડૂત ખાતેદાર છો તે બતાવતું પ્રમાણપત્ર.
  • ફાર્મર ID (ખેડૂત નોંધણી — Farmer Registry)દરેક ખેડૂતનો ડિજિટલ ઓળખ નંબર — આધાર અને જમીનના રેકર્ડ સાથે જોડાયેલો.
  • વીજળી જોડાણ પોતાના નામે (નામ ફેર)ઘર ખરીદ્યા કે વારસામાં મળ્યા પછી લાઈટ બિલ પોતાના નામે કરાવવું.
  • ફેરફાર નોંધ (ગામ નમૂના નં. 6 / હક્કપત્રક)જમીનમાં વેચાણ, વારસાઈ, બોજો કે નામ ફેરની નોંધ — અને તેની નકલ.

માહિતી: 04/11/26 સુધીની, સરકારી સાઇટ પરથી આપણા સરળ શબ્દોમાં. જાણકાર સરકારી એપ નથી; નિયમ, ફી કે તારીખ બદલાઈ શકે — અરજી પહેલાં સત્તાવાર સાઇટ પર ખાતરી કરો. ભૂલ દેખાય તો જણાવો.
