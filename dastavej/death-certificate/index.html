મરણનો દાખલો

અવસાનની નોંધણી અને દાખલો — 21 દિવસમાં નોંધણી મફત. વારસાઈ, પેન્શન, વીમા અને બેંક કામમાં જોઈએ.

કુટુંબ: જન્મ, મરણ, લગ્ન, રેશનકાર્ડ

શેમાં કામ આવે

વારસાઈ નોંધ, ગંગા સ્વરૂપા સહાય, રાષ્ટ્રીય કુટુંબ સહાય, વીમાનો દાવો, બેંક ખાતું / પેન્શન બંધ-ચાલુ કરવું.

કોણ કઢાવી શકે

  • અવસાન પામનારના કુટુંબના સભ્ય / જાણ કરનાર. દવાખાનામાં અવસાન હોય તો દવાખાનું નોંધણી કરે.

જરૂરી પુરાવા (5)

  1. દવાખાના / ડૉક્ટરનું મરણ પ્રમાણપત્ર (હોય તો)
  2. અવસાન પામનારનું આધાર કાર્ડ
  3. જાણ કરનારનું આધાર કાર્ડ
  4. રહેઠાણનો પુરાવો
  5. મોડી નોંધણી: સોગંદનામું અને પંચનામું

  • CRS (ભારતના રજિસ્ટ્રાર જનરલ)

  • 🤍 વિધવા બહેન

બીજા દસ્તાવેજ

  • જન્મનો દાખલોબાળકના જન્મની નોંધણી અને દાખલો — જન્મના 21 દિવસમાં નોંધણી મફત. હવે જન્મ તારીખનો મુખ્ય પુરાવો આ જ છે.
  • રેશનકાર્ડ — નવું, નામ ઉમેરવું / કમી કરવુંસસ્તા અનાજ માટેનું કાર્ડ; કુટુંબ અને સરનામાના પુરાવા તરીકે ઘણી યોજનામાં માંગાય છે.
  • લગ્ન નોંધણી / લગ્નનો દાખલોગુજરાતમાં લગ્નની સરકારી નોંધણી — વિઝા, સરનામું બદલવું, વારસાઈ અને યોજનામાં લગ્નનો પુરાવો.
  • પેઢીનામુંકુટુંબના વારસદારોની યાદી — વારસાઈ, બેંક ખાતું, વીમો અને સહાયમાં માંગાય છે.
  • મમતા કાર્ડ (માતા અને બાળ સુરક્ષા કાર્ડ)સગર્ભાની તપાસ અને બાળકની દરેક રસીની નોંધવાળું કાર્ડ — આંગણવાડી / આરોગ્ય કેન્દ્રમાંથી મફત.

માહિતી: 25/11/26 સુધીની, સરકારી સાઇટ પરથી આપણા સરળ શબ્દોમાં. જાણકાર સરકારી એપ નથી; નિયમ, ફી કે તારીખ બદલાઈ શકે — અરજી પહેલાં સત્તાવાર સાઇટ પર ખાતરી કરો. ભૂલ દેખાય તો જણાવો.

યોજનાદસ્તાવેજજીવનના પ્રસંગઅમારા વિશેગોપનીયતા નીતિનિયમો અને શરતોડિસ્ક્લેમરકોપીરાઇટ નીતિ (DMCA)સંપર્ક
