ગુમાસ્તા ધારા નોંધણી (દુકાન / ઓફિસ)

દુકાન, ઓફિસ કે ધંધાની જગ્યાની રાજ્યના કાયદા મુજબ નોંધણી / જાણ.

ધંધો / દુકાન

શેમાં કામ આવે

ધંધાનો સરનામા સાથે પુરાવો — બેંકનું કરંટ ખાતું, લોન અને બીજી નોંધણીમાં માંગાય છે.

કોણ કઢાવી શકે

  • દુકાન, ઓફિસ, હોટલ, ગોડાઉન જેવી ધંધાની જગ્યા — કર્મચારીની સંખ્યા પ્રમાણે નોંધણી કે ફક્ત જાણ

જરૂરી પુરાવા (4)

  1. માલિકનું આધાર અને PAN
  2. ધંધાની જગ્યાનો પુરાવો (લાઈટ બિલ / વેરા પહોંચ / ભાડા કરાર)
  3. દુકાનનો ફોટો (નામના બોર્ડ સાથે)
  4. કર્મચારીની સંખ્યા અને વિગત

સત્તાવાર લિંક

  • શ્રમ અને રોજગાર વિભાગ, ગુજરાત

અરજી હંમેશાં સત્તાવાર સાઇટ પર, ગ્રામ પંચાયત કે VCE પાસે જ કરો.

આ પ્રસંગમાં કામ આવે

  • 🏪 ધંધો / દુકાન શરૂ કરવી
જાણકાર એપમાં ખોલો: સેવ કરો, પુરાવાનું ✓ લિસ્ટ વોટ્સએપ પર મોકલો

બીજા દસ્તાવેજ

  • Udyam (MSME) નોંધણીનાના-મોટા ધંધા / ઉદ્યોગની સરકારી નોંધણી — મફત, ઓનલાઈન અને આધારથી થાય છે.
  • GST નોંધણીધંધાનું વેચાણ નક્કી મર્યાદાથી વધુ હોય ત્યારે ફરજિયાત નોંધણી — gst.gov.in પર મફત.
  • FSSAI નોંધણી (ખાવાની વસ્તુનો ધંધો)ખાવાની વસ્તુ બનાવવા, વેચવા કે હોટલ-લારી ચલાવવા માટે ફૂડ સેફ્ટીની નોંધણી / લાયસન્સ.

માહિતી: 04/11/26 સુધીની, સરકારી સાઇટ પરથી આપણા સરળ શબ્દોમાં. જાણકાર સરકારી એપ નથી; નિયમ, ફી કે તારીખ બદલાઈ શકે — અરજી પહેલાં સત્તાવાર સાઇટ પર ખાતરી કરો. ભૂલ દેખાય તો જણાવો.
