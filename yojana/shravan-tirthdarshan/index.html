શ્રવણ તીર્થદર્શન યોજના

60 વર્ષ ઉપરના વડીલોની જાત્રા (બસ) ના ભાડામાં સહાય.

વૃદ્ધ

લાભ

ST બસમાં વ્યક્તિ દીઠ ₹5,000 સુધી; ખાનગી બસમાં ₹7,000 સુધી (ખરો ખર્ચ ઓછો હોય તો તેટલો).

કોને મળે

  • ગુજરાતમાં રહેતા 60 વર્ષ કે વધુ ઉંમરના વડીલ, જેમણે પહેલાં આ લાભ ન લીધો હોય; ઓછામાં ઓછા 20 યાત્રીનું ગ્રુપ, માન્ય ટ્રાવેલ એજન્ટ / આયોજક મારફત.

જરૂરી પુરાવા (4)

  1. યાત્રીની યાદી: નામ, સરનામું, જિલ્લો, જન્મ તારીખ, આધાર નંબર
  2. દરેક યાત્રીનું આધાર કાર્ડ
  3. આયોજક / એજન્ટની માન્યતાનો પુરાવો
  4. બસની વિગત (ST / ખાનગી)

સત્તાવાર લિંક

  • myScheme: Shravan Tirthdarshan Yojna

અરજી હંમેશાં સત્તાવાર સાઇટ પર, ગ્રામ પંચાયત કે VCE પાસે જ કરો.

આ પ્રસંગમાં કામ આવે

  • 👴 વડીલ (60 વર્ષ ઉપર)
જાણકાર એપમાં ખોલો: સેવ કરો, પુરાવાનું ✓ લિસ્ટ વોટ્સએપ પર મોકલો

બીજી યોજના

  • વૃદ્ધ પેન્શન (નિરાધાર વૃદ્ધ સહાય / ઇન્દિરા ગાંધી રાષ્ટ્રીય વૃદ્ધ પેન્શન)60 વર્ષથી મોટા, આધાર વગરના વડીલોને દર મહિને પેન્શન.
  • આયુષ્માન ભારત PMJAY-MA કાર્ડનક્કી કરેલી હોસ્પિટલમાં કુટુંબ દીઠ વર્ષે ₹10 લાખ સુધીની મફત (કેશલેસ) સારવાર.
  • અંત્યેષ્ટિ સહાય (વૃદ્ધ સહાય લેનારના અવસાને)વૃદ્ધ સહાય મેળવતા વડીલનું અવસાન થાય તો વારસદારને અંતિમક્રિયા માટે ₹5,000.

માહિતી: 26/11/26 સુધીની, સરકારી સાઇટ પરથી આપણા સરળ શબ્દોમાં. જાણકાર સરકારી એપ નથી, ફક્ત માહિતી આપે છે (અરજી કે સેવા નહીં); નિયમ, ફી કે તારીખ બદલાઈ શકે — અરજી પહેલાં સત્તાવાર સાઇટ પર ખાતરી કરો. ભૂલ દેખાય તો જણાવો.
