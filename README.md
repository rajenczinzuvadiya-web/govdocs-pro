# જાણકાર

ગામના દરેક માણસને તેના માટે કઈ યોજના, સહાય અને દાખલાની માહિતી છે તે સરળ ગુજરાતીમાં, વાંચીને સંભળાવીને જણાવતી એપ. KruPa Digital Hub ની એપ.

- નામ: **જાણકાર** (ટેગલાઇન નથી). Play Store માં: "જાણકાર: યોજના, સહાય, દાખલા"; ભરતી વિભાગ બને પછી "ભરતી" ઉમેરવું.
- સરનામું: `https://jankar.krupadigitalhub.in` (સેટિંગની રીત `store/README.md` માં).
- KruPa ની ત્રણ એપ: **જાણકાર** (ગ્રામજનો, Play Store), **KruPa Digital Hub** (VCE, વેબ), **KruPa Doc Hub** (ઝેરોક્ષ દુકાન, વેબ). જાણકારના મેનુમાં "ઓપરેટર માટે" બંનેની લિંક છે (`js/config.js` → `krupa`).
- નામ બદલાય તો: `js/config.js`, `manifest.json`, `index.html`, `icons/icon-source.png`, `store/feature-bg.png`, `store/listing.md`, `scripts/store-images.mjs`.

## દેખાવ (KruPa Digital Hub જેવો)

- વાદળી + સફેદ રંગ, લાઈટ / ડાર્ક / ઓટો દેખાવ, ઝૂમ 80–120% (ઉપર જમણી બાજુ મેનુ).
- Hind Vadodara font એપની અંદર (`fonts/`, SIL Open Font License).
- KruPa ના જ line આઇકન અને રંગીન tile આઇકન (`js/icons.js`; tile આઇકન Font Awesome Free, CC BY 4.0).
- ફોન: નીચે 5 ટેબ. કમ્પ્યુટર: ડાબી બાજુ વાદળી મેનુ અને આખી પહોળાઈ.
- વિગતના પેજ પર KruPa ગાઈડ જેવું: લાભ / કોને મળે, ફી-દિવસ-માન્યતા, પુરાવાનું ✓ લિસ્ટ, પગલાંની timeline, ભૂલો, અરજી પછી, બાજુમાં મદદ અને સ્રોત.

## માહિતી ક્યાંથી આવે (16/11/26 થી)

યોજના, દસ્તાવેજ અને પ્રસંગ KruPa Digital Hub → એડમિન → ગાઇડ મેનેજમાં લખાય છે. ત્યાં "ચાલુ" કરેલું કાર્ડ દર 3 કલાકે અહીં આવે (`from: "hub"`), ત્યાં બંધ કરો તો અહીંથી જાય. તરત જોઈએ તો GitHub → Actions → "Digital Hub માંથી માહિતી" → Run workflow. `from: "hub"` વાળું કાર્ડ અહીં બદલશો તો આવતી વખતે પાછું Digital Hub જેવું થઈ જશે, એટલે સુધારો Digital Hub માં કરવો.

## ફોનમાં ચલાવીને જોવું

```
python3 -m http.server 8080
```

પછી બ્રાઉઝરમાં `http://localhost:8080` ખોલો. ફાઇલ સીધી ડબલ-ક્લિક કરીને ખોલવાથી નહીં ચાલે, કારણ કે ડેટા `fetch` થી આવે છે.

## KruPa Digital Hub માંથી આવેલો ડેટા

34 યોજના ગાઈડ, 39 દસ્તાવેજ ગાઈડ અને 13 પ્રસંગ KruPa Digital Hub ના કોડમાંના **તૈયાર ડ્રાફ્ટ** (`src/lib/guides/ready*.ts`) પરથી લીધાં છે (`"from": "krupa"`).
KruPa ના admin માં ચકાસેલી/સુધારેલી ગાઈડ Supabase માં છે, તે અહીં આવી નથી.
ઓપરેટર માટેની "વધુ માહિતી (લોગિન પછી)", ફોર્મ, ટૂલ અને screenshot જાણી જોઈને નથી લાવ્યા.
બંનેમાં હતી તેવી 28 યોજના/દસ્તાવેજમાં KruPa નું લખાણ લીધું, અને આ એપનું id, વર્ગ, નિયમ અને છેલ્લી તારીખ રાખ્યાં.
લખાણમાં "⚠️ ચકાસો" હોય તે વાત સત્તાવાર સાઇટ પર ખાસ ચકાસવી.

## નવું યોજના કાર્ડ ઉમેરવું

`data/schemes.json` માં આ રીતે ઉમેરો:

```json
{
  "id": "nani-angreji-id",
  "title": "યોજનાનું નામ",
  "summary": "એક લીટીમાં શું છે",
  "categories": ["khedut"],
  "benefit": "શું મળશે",
  "eligibility": ["કોણ લાયક — દરેક શરત અલગ લીટીમાં"],
  "documents": ["આધાર કાર્ડ", "..."],
  "howToApply": "ક્યાં અને કેવી રીતે અરજી",
  "lastDate": "2026-12-31",
  "officialLink": "https://...",
  "source": "સ્રોતનું નામ",
  "updatedOn": "2026-11-16",
  "verified": false,
  "rules": { "minAge": 18, "maxAge": 35, "maxIncome": 250000, "jati": ["sc", "st"] }
}
```

- `lastDate`: ચાલુ યોજના હોય તો `null`.
- `rules` વૈકલ્પિક છે. પ્રોફાઇલમાં જે માહિતી ભરી ન હોય તેના આધારે યોજના છુપાતી નથી.
- વર્ગ (`categories`): `khedut`, `vidyarthi`, `yuvan`, `mata`, `vali`, `vrudh`, `vidhva`, `divyang`, `shikshak`, `vepari`, `samanya`. `samanya` વાળી યોજના દરેકને દેખાય છે.
- સત્તાવાર પેજ પરથી ચકાસ્યા પછી જ `"verified": true` કરવું.

ઉમેર્યા પછી ચકાસો:

```
node scripts/check-data.mjs
```

કોડ બદલો ત્યારે `sw.js` માં `VERSION` વધારો, જેથી યુઝર્સના ફોનમાં નવું વર્ઝન આવે. ફક્ત `data/` બદલો ત્યારે તેની જરૂર નથી.
