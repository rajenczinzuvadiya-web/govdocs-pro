# Play Store નું લખાણ (કોપી-પેસ્ટ માટે)

Play Console માં દરેક ખાનામાં નીચેનું લખાણ કોપી કરીને મૂકો.

## એપનું નામ (30 અક્ષર સુધી)

```
ગામની જાણકારી: યોજના ગાઈડ
```

## ટૂંકું વર્ણન (80 અક્ષર સુધી)

```
યોજના, દાખલા અને સહાયની માહિતી સરળ ગુજરાતીમાં. ખાનગી એપ, સરકારી નથી.
```

## પૂરું વર્ણન

```
ગામની જાણકારી ગામના દરેક માણસને સરળ ગુજરાતીમાં જણાવે છે કે તેને કઈ યોજના અને સહાય મળી શકે, અને તે કેવી રીતે મેળવવી.

એપમાં શું છે:
• યોજના ગાઈડ: ખેડૂત, વિદ્યાર્થી, યુવાન, માતા, વૃદ્ધ, વિધવા, દિવ્યાંગ, વેપારી માટેની યોજનાઓ. કોને મળે, કેટલો લાભ, કયા પુરાવા, ફી, કેટલા દિવસ અને અરજીનાં પગલાં.
• દસ્તાવેજ ગાઈડ: આવકનો દાખલો, જાતિનો દાખલો, આધાર, રેશનકાર્ડ, જન્મનો દાખલો જેવા દાખલા ક્યાંથી અને કેવી રીતે કઢાવવા.
• જીવનના પ્રસંગ: બાળકનો જન્મ, લગ્ન, ઘડપણ, નવું ઘર જેવા પ્રસંગે શું કરવું તેનું લિસ્ટ.
• સાંભળો: એપ માહિતી ગુજરાતીમાં વાંચીને સંભળાવે છે.
• વોટ્સએપ પર મોકલો: કામની યોજના એક બટનથી બીજાને મોકલો.
• પુરાવાનું લિસ્ટ: તૈયાર થાય તેમ ✓ કરો.
• જરૂરી ફોન નંબર: ટેપ કરો એટલે ફોન લાગે.
• મોટા અક્ષર અને ડાર્ક દેખાવ.
• નેટ વગર પણ ખૂલે છે.

તમારી માહિતી સુરક્ષિત:
• લોગિન નથી, જાહેરાત નથી.
• પ્રોફાઇલ ફક્ત તમારા ફોનમાં રહે છે.
• અમે ક્યારેય પૈસા, OTP કે આધાર નંબર માંગતા નથી.

મહત્વની સૂચના:
આ ખાનગી માહિતી એપ છે. તે કોઈ સરકારી વિભાગની સત્તાવાર એપ નથી, અને સરકાર સાથે જોડાયેલી નથી. એપ કોઈ અરજી કે સરકારી સેવા આપતી નથી.

માહિતીનો સ્રોત:
માહિતી સરકારની સત્તાવાર વેબસાઇટ પરથી લેવામાં આવે છે, જેમ કે:
https://www.digitalgujarat.gov.in
https://esamajkalyan.gujarat.gov.in
https://wcd.gujarat.gov.in
https://pmkisan.gov.in
https://www.india.gov.in
દરેક કાર્ડ પર મૂળ સ્રોતની લિંક છે. અરજી પહેલાં સત્તાવાર સાઇટ કે કચેરીમાં ખાતરી કરો.
```
