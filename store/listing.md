# Play Store નું લખાણ (કોપી-પેસ્ટ માટે)

Play Console માં દરેક ખાનામાં નીચેનું લખાણ કોપી કરીને મૂકો.

## એપનું નામ (30 અક્ષર સુધી)

```
જાણકાર: યોજના, સહાય, દાખલા
```

## ટૂંકું વર્ણન (80 અક્ષર સુધી)

```
યોજના, સહાય અને દાખલાની માહિતી સરળ ગુજરાતીમાં. ખાનગી એપ, સરકારી નથી.
```

## પૂરું વર્ણન

```
જાણકાર ગામના દરેક માણસને સરળ ગુજરાતીમાં જણાવે છે કે તેને કઈ યોજના અને સહાય મળી શકે, અને તે કેવી રીતે મેળવવી.

મહત્વની સૂચના:
આ KruPa Digital Hub ની ખાનગી માહિતી એપ છે. તે કોઈ સરકારી વિભાગની સત્તાવાર એપ નથી, અને સરકાર સાથે જોડાયેલી નથી. એપ કોઈ અરજી કે સરકારી સેવા આપતી નથી.

એપમાં શું છે:
• યોજના ગાઈડ: ખેડૂત, વિદ્યાર્થી, યુવાન, માતા, વૃદ્ધ, વિધવા, દિવ્યાંગ, વેપારી માટેની યોજનાઓ. કોને મળે, કેટલો લાભ, કયા પુરાવા, ફી અને સત્તાવાર લિંક.
• દસ્તાવેજ ગાઈડ: આવકનો દાખલો, જાતિનો દાખલો, આધાર, રેશનકાર્ડ, જન્મનો દાખલો જેવા દાખલા શેમાં કામ આવે અને કયા પુરાવા જોઈએ.
• તમારા માટે યોજના શોધો: તમે કોણ છો, શું કરો છો, આવક જેવા થોડા જવાબ — લાગુ પડી શકે એવી યોજના.
• જીવનના પ્રસંગ: બાળકનો જન્મ, લગ્ન, ઘડપણ, નવું ઘર જેવા પ્રસંગે શું કરવું તેનું લિસ્ટ.
• ફરજિયાત દસ્તાવેજ: દરેક પાસે હોવા જોઈએ એવા દસ્તાવેજનું ✓ લિસ્ટ.
• ધ્યાન રાખો: ફ્રોડથી સાવધાન, સામાન્ય ભૂલો અને જરૂરી સૂચના.
• જરૂરી ફોન નંબર: દરેક નંબર ક્યારે કામ આવે તેની વિગત, ટેપ કરો એટલે ફોન લાગે.
• વોટ્સએપ પર મોકલો: કામની યોજના એક બટનથી બીજાને મોકલો.
• મોટા અક્ષર, ડાર્ક દેખાવ, ફોટો મોટો કરીને જુઓ.

તમારી માહિતી સુરક્ષિત:
• જાહેરાત નથી. લોગિન નથી.
• પ્રોફાઇલ અને જવાબ ફક્ત તમારા ફોનમાં રહે છે.
• "સંપર્ક અને સૂચન" માં તમે લખેલું લખાણ જાય છે; નામ અને મોબાઇલ નંબર લખવા વૈકલ્પિક (ફક્ત જવાબ આપવા).
• અમે ક્યારેય પૈસા, OTP કે આધાર નંબર માંગતા નથી.

માહિતી સરકારની સત્તાવાર વેબસાઇટ પરથી લેવામાં આવે છે, જેમ કે:
```

## Data safety ફોર્મના જવાબ (24/11/26 બદલ્યા: નામ + ફોન નંબર ઉમેર્યા)

એપ હવે બે વસ્તુ અમારા સર્વર (KruPa Digital Hub) પર મોકલે છે: તમે જાતે લખો તે "ભૂલ / સૂચન" (સાથે, લખો તો, નામ અને મોબાઇલ નંબર), અને એપની ભૂલની આપોઆપ નોંધ. બંને સાથે ફોને બનાવેલો 8 અક્ષરનો રેન્ડમ નંબર જાય છે. Google આને "collect" ગણે છે, એટલે "No" ખોટું ગણાય. પ્રોફાઇલ, સેવ અને ચેકલિસ્ટ ફોનમાં જ રહે છે (એ collect નથી).

|---|---|---|---|---|
| Personal info → Name | ✓ | No | Optional (સંપર્ક ફોર્મમાં લખે તો જ) | Developer communications |
| Personal info → Phone number | ✓ | No | Optional (સંપર્ક ફોર્મમાં લખે તો જ) | Developer communications |
